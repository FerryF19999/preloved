# NEMU Preloved prototype

Static, local-only marketplace prototype using a public NEMU catalogue snapshot dated **5 November 2026**. Not a production storefront; no login, inventory reservation, payment, or real order is created.

## Run

Python 3.10+; build and static serving use only the standard library.

```sh
python3 build.py
python3 -m http.server 4188 --bind 127.0.0.1
```

Open `http://127.0.0.1:4188/#preloved`.

`index.html` and required assets are committed, so any static host can serve the repository without a build step. Enable gzip/Brotli at the host. Live preview: https://ferryf19999.github.io/preloved/#preloved (GitHub Pages, main branch). The temporary SSH tunnel is not the supported preview; its bandwidth caused incomplete page loads.

## Catalogue-backed experiences

- **Virtual Fit:** original spatial room, glass controls, orbital product carousel and scan/reveal animation, now using genuine NEMU catalogue photos and metadata. Browse by category, swipe, use arrow keys, inspect the source listing and add the actual UUID to the shared demo bag. This is a visual catalogue preview, not AI try-on or sizing prediction.
- **Try the Look:** original animated runway/ring, look transitions, product hotspots, zoom and product panel, populated with compositions of genuine NEMU catalogue photographs. These compositions are not model-wearing-outfit photographs. Individual products and look bundles use actual UUIDs and IDR prices in the shared local demo bag.
- Both use the **181 fashion products from 450 Preloved seller listings**. No external reference-model clothing or invented sizes/prices are used in these workspaces.
- The complete 5,041-product snapshot loads only when the full catalogue is requested. Initial bootstrap includes Preloved listings plus one explicit group-demo dependency; extra gallery metadata is deferred.
- Meetups, shipping, buyer rewards, and group purchases are explicitly simulated. Seller funding is used in shipping scenarios; NEMU subsidy is zero.

## Files

- `catalog.json`: normalized public catalogue snapshot; source listing URLs, original image URLs, seller display names, prices, conditions and stock retained.
- `thumbs/`: 450 WebP derivatives of the catalogue photos, used for lightweight previews.
- `details/`: deferred gallery metadata generated by the build.
- `discovery-template.html`, `*.js`, `*.css`: editable source. Rebuild after changes.
- `virtualfit.html`, `runway.html`: restored visual interfaces, lazy-loaded only when opened.
- `nemu-fashion.js`, `preloved-fashion.json`: shared actual catalogue data and local bag adapter.
- `tests/test_studio.py`: actual browser integration tests at 320px, 390px, and desktop width.

## Browser verification

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements-dev.txt
playwright install chromium
# The test starts its own temporary static server.
python tests/test_studio.py
```

Screenshots and JSON evidence are written to `.test-results/` (ignored by Git). The integration test starts a temporary local HTTP server and covers lazy loading, real catalogue availability, mobile frame layout, shared bag synchronization and duplicate prevention. No private photo upload feature is included.

Public catalogue data/images remain attributable to their original sellers and NEMU. Prices, availability and condition are historical seller-provided snapshot data, not live guarantees. No rights beyond the source owners' rights are asserted. Private user uploads and credentials are not included in this repository.
